### 2.4 Reference Equation Schema

Each record contains:
- `reference_id`: Stable ID from HTML node ID (e.g., "m1", "m2")
- `paper_id`: arXiv ID
- `html_index`: Position in HTML corpus
- `node_id`: MathML node ID from arxiv HTML
- `latex`: LaTeX annotation from `<annotation encoding="application/x-tex">`
- `mathml`: Full MathML markup from `<math>` tag
- `mathml_len`: Length of MathML string
- `is_display`: Whether display or inline equation
- `context_before/after`: Surrounding text
- `source`: Always "mathml" (from arxiv HTML)
- `page_number`: null (HTML corpus doesn't have page numbers)
- `location_evidence`: "html_node" or "html_index"
